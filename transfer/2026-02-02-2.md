## Build/Test Commands

```sh
# Build
goreleaser release --clean --snapshot

# Run unit tests
go test ./...

# Run integration tests (requires Docker)
go test -tags=integration ./internal/proxy/...

# Run with telemetry to stdout
dist/tcpproxy_linux_amd64_v1/tcpproxy \
  -proxy 8080=httpbin.org:80 \
  -telemetry-enabled \
  -telemetry-exporter stdout

# Run with OTLP collector
OTEL_EXPORTER_OTLP_ENDPOINT=localhost:4317 \
dist/tcpproxy_linux_amd64_v1/tcpproxy \
  -proxy 8080=httpbin.org:80 \
  -telemetry-enabled
```
